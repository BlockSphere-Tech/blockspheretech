# BlockSphere Tech

Enterprise blockchain infrastructure marketing site — Next.js (App Router) + Tailwind CSS.

Frontend-only. All copy, products, networks, FAQ, and pricing logic live in the app (no separate API server).

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Languages

English, 中文, and Español — switcher in the header/footer. Preference is saved in `localStorage`.

## Deploy to Vercel

1. Import this repo in [Vercel](https://vercel.com/new).
2. Framework preset: **Next.js** (auto-detected). Leave Root Directory as `.`.
3. Deploy — no environment variables required.

Or from the CLI:

```bash
npx vercel
```
